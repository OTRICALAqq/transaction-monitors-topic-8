# Мониторы транзакций

Учебные материалы по теме 8 дисциплины «Распределённые и облачные вычисления».

- [Виртуальная доска](https://otricalaqq.github.io/transaction-monitors-topic-8/board.html)
- [Интеллектуальная карта](https://otricalaqq.github.io/transaction-monitors-topic-8/mindmap.html)
- [PDF доски](board.pdf)
- [PDF карты](mindmap.pdf)

Доска систематизирует назначение монитора транзакций, ACID, архитектуру X/Open DTP, двухфазную фиксацию, восстановление и условный пример перевода средств. Интеллектуальная карта раскрывает восемь ветвей темы.

На страницах доступны поиск, масштабирование и загрузка PDF. Файлы `.drawio` можно открыть в diagrams.net. SVG и PDF содержат одинаковые тексты, связи и расположение элементов. Технические источники приведены на главной странице.

Пример перевода является учебной моделью с условными данными.
